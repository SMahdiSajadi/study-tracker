# 📚 سامانه جامع مدیریت و ثبت ساعات مطالعه (Study Tracker)

![Python Badge](https://img.shields.io/badge/Python-3.10-blue?style=for-the-badge&logo=python&logoColor=white)
![Django Badge](https://img.shields.io/badge/Django-5.0-092E20?style=for-the-badge&logo=django&logoColor=white)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-316192?style=for-the-badge&logo=postgresql&logoColor=white)
![HTML/CSS/JS](https://img.shields.io/badge/Frontend-Vanilla-E34F26?style=for-the-badge&logo=html5&logoColor=white)

یک پلتفرم تحت وب مینیمال، سریع و قدرتمند که با فریم‌ورک **Django** توسعه یافته است. این سامانه به دانش‌آموزان، داوطلبان کنکور و دانشجویان کمک می‌کند تا ساعات مطالعه روزانه خود را به تفکیک رشته تحصیلی و درس ثبت کنند. همچنین مدیران سیستم می‌توانند به راحتی از طریق پنل مدیریت، گزارش‌های دقیقی از عملکرد کاربران دریافت کنند.

---

## ✨ امکانات اصلی پلتفرم

- **معماری داینامیک:** قابلیت تعریف بی‌نهایت رشته تحصیلی و اتصال دروس زیرمجموعه به هر رشته.
- **رابط کاربری تعاملی و جذاب:** فرم‌های داینامیک ثبت مطالعه با جاوا اسکریپت خالص جهت افزودن چندین درس به صورت همزمان بدون نیاز به رفرش صفحه.
- **خروجی اکسل پیشرفته:** دریافت فایل اکسل (`.xlsx`) از کل ساعات مطالعه دانش‌آموزان تنها با یک کلیک (مختص حساب مدیریت).
- **سیستم مدیریت ایزوله و امن:** اکانت‌ها مستقیماً توسط مدیر در پنل ادمین ساخته می‌شوند تا از ثبت‌نام‌های نامرتبط جلوگیری شود.
- **عملکرد بهینه (Local-First):** استفاده از استایل‌های خام (Vanilla CSS) و عدم وابستگی به فریم‌ورک‌های سنگین فرانت‌اند برای لودینگ فوق‌سریع.

---

## 🛠️ تکنولوژی‌های استفاده شده

* **بک‌اند:** Python, Django, Gunicorn, WhiteNoise
* **دیتابیس:** SQLite (محیط توسعه) / PostgreSQL (محیط پروداکشن)
* **فرانت‌اند:** HTML5, CSS3, Vanilla JS
* **مدیریت داده‌ها:** OpenPyXL (برای خروجی اکسل)

## 🚀 راهنمای نصب و راه‌اندازی (Local Setup)

برای اجرای این پروژه روی سیستم شخصی خود جهت توسعه و تست، مراحل زیر را به ترتیب در ترمینال (Terminal) اجرا کنید:

**۱. کلون کردن پروژه از گیت‌هاب:**
```bash
git clone [https://github.com/SMahdiSajadi/study-tracker.git](https://github.com/SMahdiSajadi/study-tracker.git)
cd study-tracker
```

**۲. ساخت و فعال‌سازی محیط مجازی (Virtual Environment):
```bash
# ساخت محیط مجازی
python -m venv venv

# فعال‌سازی در سیستم‌عامل Windows:
.\venv\Scripts\activate

# فعال‌سازی در سیستم‌عامل Mac/Linux:
source venv/bin/activate
```

**۳. نصب نیازمندی‌ها و کتابخانه‌ها:
```bash
pip install -r requirements.txt
```

**۴. اجرای دیتابیس و روشن کردن سرور:
```bash
# ساخت جداول دیتابیس
python manage.py migrate

# ساخت حساب کاربری مدیریت (Superuser)
python manage.py createsuperuser

# روشن کردن سرور محلی
python manage.py runserver
```

# ⚙️ راهنمای پنل مدیریت و ثبت اطلاعات پایه

پس از اجرای موفق سرور، برای اینکه سایت به درستی کار کند باید اطلاعات پایه را وارد کنید:

1. وارد مسیر `http://127.0.0.1:8000/admin` شوید و با حساب مدیریتی که ساختید لاگین کنید.

2. در بخش **رشته‌های تحصیلی (Majors)**، رشته‌های مورد نیاز (مانند ریاضی فیزیک، علوم تجربی و...) را اضافه کنید.

3. در بخش **دروس (Subjects)**، درس‌های مختلف را ایجاد کرده و هر کدام را به رشته مربوطه‌اش متصل کنید.

4. در بخش **کاربران (Users)**، حساب‌های کاربری دانش‌آموزان را بسازید و حتماً از انتهای فرم، **رشته تحصیلی** آن‌ها را مشخص کنید تا داشبورد آن‌ها به درستی لود شود.

# 🌐 استقرار روی سرور (Deployment)

این پروژه برای استقرار روی پلتفرم‌هایی نظیر **Render.com** یا **Liara** کاملاً بهینه‌سازی شده است. تنظیمات مربوط به `WhiteNoise` برای مدیریت فایل‌های Static و ابزار `dj-database-url` برای اتصال امن به دیتابیس ابری PostgreSQL به صورت پیش‌فرض در فایل `settings.py` کانفیگ شده‌اند. فایل `build.sh` نیز جهت اجرای خودکار فرآیند بیلد در سرور قرار داده شده است.
